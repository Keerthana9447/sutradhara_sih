# --- Dense retrieval (BGE embeddings) — OPTIONAL, NOT installed by default ---
# app/retrieval.py's primary, always-installed retrieval path is TF-IDF
# (scikit-learn, already listed above) — deliberately, so the default
# install here stays light enough for Render's free/starter tiers: no
# onnxruntime, no faiss, no multi-hundred-MB model download during build.
# fastembed gives BAAI/bge-small-en-v1.5 dense retrieval instead, using
# NumPy for exact cosine similarity (no FAISS dependency). It is still
# fully supported by the code, but must be installed separately:
# `pip install -r requirements-embeddings.txt` in an
# environment with more build time/memory/bandwidth to spare. Without it,
# app/retrieval.py falls back to TF-IDF automatically — no code change, no
# flag to flip. See requirements-embeddings.txt and app/retrieval.py's
# module docstring for the full explanation.

# --- Deterministic pipeline orchestration (app/dag.py) ---
# Wires the /api/analyze pipeline (classify -> route -> retrieve -> score ->
# answer -> translate) as an explicit LangGraph StateGraph with plain
# if/else conditional edges on already-computed state (needs_clarification,
# abstained) -- never an LLM-driven routing decision, so the graph shape is
# fully deterministic and reproducible. If this package is missing or fails
# to import, app/dag.py falls back to `_run_sequential`, a hand-written
# executor that calls the exact same node functions in the exact same
# order/branches with zero LangGraph dependency -- same not-installed-by-
# default-still-works pattern as the embeddings split above.
