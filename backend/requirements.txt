# --- Deterministic pipeline orchestration (app/dag.py) ---
# Wires the /api/analyze pipeline (classify -> route -> retrieve -> score ->
# answer -> translate) as an explicit LangGraph StateGraph with plain
# if/else conditional edges on already-computed state (needs_clarification,
# abstained) -- never an LLM-driven routing decision, so the graph shape is
# fully deterministic and reproducible. If this package is missing or fails
# to import, app/dag.py falls back to `_run_sequential`, a hand-written
# executor that calls the exact same node functions in the exact same
# order/branches with zero LangGraph dependency -- same pattern as the
# fastembed/faiss-cpu fallback to TF-IDF above.
